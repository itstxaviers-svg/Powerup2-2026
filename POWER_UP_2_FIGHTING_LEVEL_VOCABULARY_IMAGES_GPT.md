# POWER UP 2 — FIGHTING LEVEL VOCABULARY PICTURE CLUES

## MODEL TASK

Create a consistent production set of vocabulary picture clues for the existing **Power Up 2** children's English learning game.

These images will be used inside Fighting Level questions where the learner sees a picture and types the English word or phrase.

Generate every requested image as a **separate downloadable PNG file**. Do not create a collage, contact sheet, sprite sheet, PDF, concept sheet, or combined image.

## IMPORTANT WORKFLOW

1. Generate one image per vocabulary item.
2. Use the exact filename specified below.
3. Keep the visual style consistent across the entire set.
4. Do not add any written answer, label, letter, number, logo, or watermark.
5. Each picture must communicate only the requested word or phrase.
6. If a result is ambiguous, regenerate it before delivering it.
7. Preserve genuine background transparency in the exported PNG.
8. Deliver all files individually so they can be saved directly into the production folders.

## OUTPUT SPECIFICATION

- File format: PNG
- Canvas: 1024 × 1024 px
- Colour profile: sRGB
- Background: genuinely transparent alpha background
- Framing: square
- Subject size: approximately 70–80% of the canvas
- Safe margin: approximately 10–12% on every side
- The complete subject must be visible
- Do not crop important parts of the subject
- One central object or one clearly readable action per image
- No decorative border
- No UI elements
- No text or typography of any kind
- No logos, product branding, watermarks, signatures, or readable packaging

## PHRASE THAT MUST NOT RECEIVE A SEPARATE IMAGE YET

Do not generate a separate picture for:

```text
to protect a project
```

If the intended meaning is “to defend/present a school project”, its picture would be visually indistinguishable from `have a presentation`. That would create an ambiguous vocabulary question. Keep this phrase as an audio question unless a clearly different intended meaning is supplied.
